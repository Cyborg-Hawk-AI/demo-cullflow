## Local development

### Prerequisites

- Node.js 18+ and npm

### Setup

```bash
npm install
npm run dev    # http://localhost:3000
```

The dev server hot-reloads. Open [http://localhost:3000](http://localhost:3000) for the landing page, or go directly to:

- `/demo` — interactive product mock (all MVP features)
- `/developers` — feature documentation and production integration notes
- `/research` — validation research and source pain points

### Production build

```bash
npm run build  # required before deploy
npm start      # serve production build locally
```

### Deploy to Vercel

Push to a Git repo and import in Vercel, or run `npx vercel` from this directory. No environment variables, custom server, or `vercel.json` rewrites are required — the App Router handles all routes via file-based routing under `app/`.

```
app/
  page.tsx          # Landing page
  demo/page.tsx     # Interactive demo
  developers/       # Developer documentation
  research/         # Research story
  layout.tsx        # Root layout (header + footer)
components/         # Shared UI and demo components
lib/mock-data.ts    # Hardcoded sample data for the demo
```
